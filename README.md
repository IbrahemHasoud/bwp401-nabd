# نبض الجامعة | Nabd Campus

مشروع مستقل لمقرر BWP401 — الكلاس 7 — د. باسل الخطيب.

أجندة للفعاليات الجامعية، بهوية خضراء وليمونية، وشريط أيام أسبوعية، وقائمة مواعيد، وعرضين للفعاليات: بطاقات وأجندة. المشروع مختلف في الاسم والمحتوى والصور والتخطيط عن مشروع ملتقى السابق.

## الصفحات والتشغيل

افتح index.html، أو ارفع ملفات المشروع إلى استضافة ثابتة. لا توجد عملية بناء أو مكتبات تطبيقات أو قاعدة بيانات.

- index.html: الفريق، الواجهة، التصنيفات، أجندة أسبوعية، سلايدر، أحدث الفعاليات.
- events.html: ثماني فعاليات مع البحث والتصفية حسب التصنيف والتاريخ والمكان، وعرض بطاقات أو أجندة.
- event.html: تفاصيل متغيرة بحسب id، صور، برنامج، صورة موقع تخطيطية، تقويم، مشاركة، وفعاليات ذات صلة.
- about.html: الهدف والرؤية والرسالة والفريق وسياسات النشر ومصادر الصور.
- contact.html: التحقق من الاسم والبريد والرسالة وعرض Bootstrap Alerts.
- en/: ترجمة الصفحات الخمس إلى الإنجليزية مع LTR.

Bootstrap 5.3.3 عبر CDN، مع نسخ احتياطية محلية. الصور وخط Cairo محفوظة محليًا. تحفظ اللغة والمظهر في localStorage متى سمح المتصفح، ويُفضّل HTTP/HTTPS لحفظ التفضيلات باستمرار بين الصفحات.

## الاعتماد الدراسي

HTML والصور والروابط: CH1. النماذج وHTML5 وSVG: CH2. CSS والتنسيق والخطوط: CH3. الوظائف والمصفوفات والشروط والتعابير النمطية: CH4. DOM والأحداث والتحقق من الإدخال: CH5. الوثائق الديناميكية والإظهار والإخفاء وتغيير التنسيق: CH6. Bootstrap وGrid/Flex والتجاوب وملفات التقويم والمشاركة مطلوبة في ملف الوظيفة، وحفظ التفضيلات والوضع الداكن مذكوران كإضافات اختيارية. الترجمة بطلب المستخدم.

ملفات Python الخاصة بتوليد المحتوى والتحقق أدوات إعداد محلية، وليست جزءًا من الموقع أو تقنية يحتاج الطالب إلى تشغيلها أو تثبيتها.

## بيانات تجريبية وتراخيص

المواعيد والأماكن والفعاليات أمثلة غير رسمية. صور Pexels توضيحية ولا توثّق الجامعة أو الفريق؛ روابطها في IMAGE-SOURCES.md وصفحة عن الدليل. صور الفريق رموز حرفية. عنوان hello@nabd.example وروابط المنصات عامة وتوضيحية. النموذج يتحقق محليًا فقط؛ لا تُرسل الرسائل ولا تُخزن بيانات النموذج.

Bootstrap بترخيص MIT المرفق. خط Cairo بترخيص OFL المرفق. لا تمنح تراخيص المكتبات أي ترخيص جديد لصور Pexels؛ يرجع استخدامها إلى ترخيص المصدر المرتبط في صفحة الصور.
